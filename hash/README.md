# Hash

## 개념
해시 테이블은 키(key)를 값(value)에 매핑해서 저장하는 자료구조
평균 O(1)로 데이터를 찾고, 넣고, 지울 수 있음
키를 해시 함수에 넣어서 나온 값을 인덱스처럼 사용

## 자료구조
### 맵 
키-값 쌍을 저장하려 할 때

#### 정의
```cpp
unordered_map<K, V> m;
```

#### 새 요소 삽입
```cpp
m[key] = value;
m[key]++;
```

### 셋
키만 저장하려 할 때. 값에 중복이 없을 때 사용
```cpp
unordered_set<K> s;
```

#### 새 요소 삽입
```cpp
s.insert(key);
```

#### 기존 요소 찾기
key가 존재하면 이터레이터 반환. 아니라면 `s.end()` 반환. 이터레이터가 가리키는 값에 접근하려면 역참조(`*`)를 사용.
```cpp
s.find(key);
```
